Practice / 03

The way I tend to work.

Clear enough to move. Curious enough to change direction.

01

Start with the real problem

Make the user need, the constraint, and the decision in front of the team visible before reaching for a solution.

02

Build the loop

Keep discovery, delivery, and measurement close enough that learning can change the plan while there is still time to use it.

03

Leave a useful trail

Good product systems help the next person understand what happened, why it mattered, and what to do next.
